🔹 Как работает программа

Это обычная программа (не настоящий бот), которая:
	1.	Спрашивает у пользователя сумму
	2.	Переводит её в доллары
	3.	Выводит результат

🔹 Разбор кода по строкам

print("Конвертер валют")

➡️ Просто выводит текст на экран

som = float(input("Введите сумму в сомах: "))

➡️ input() — просит пользователя ввести число
➡️ float() — превращает введённый текст в число
➡️ Сохраняет это число в переменную som

dollar = som * 0.011

➡️ Умножает сумму на курс (0.011)
➡️ Сохраняет результат в dollar

print("В долларах:", dollar)

➡️ Показывает результат пользователю

🔹 Пример работы

Ты запускаешь программу:

Конвертер валют
Введите сумму в сомах: 1000

Программа считает:

1000 × 0.011 = 11

И выводит:

В долларах: 11

🔹 Важно понять
	•	som — это твои деньги в сомах
	•	0.011 — курс доллара
	•	программа просто делает умножение
